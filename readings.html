探索路径

四条线的路径导航：✓ 成功 · ✗ 失败 / 此路不通 · ◐ 外部 / 未定。点击节点进入详细读解。

线一 · 缺口定位 ✓ 成功

起点是 Langlands 纲领的「连接」，终点落到 (Spec ℤ, 零点结构) 这一格。

  • ✓ 把「缺一个统一理论」压缩到「缺一格」——从一整片未知，缩小到一个可命名的一格。
  • ✓ 结论：缺的是正性，不是「连接」。
  • ◐ 过程含三次自我更正（尤其 Connes 算子非自伴一条），边界感见 综述 §2.3。

线二 · 正性地形 ✗ 走不通

沿 Connes → Weil 正性 → Suzuki → de Branges 一路勘察，结果 12 条路逐一排除，撞上 4 堵墙。

  • ✗ 12 条路排除——每条都是「此路不通」，但排除本身是成果（证伪成功）。
  • ✗ 4 堵墙，其中最硬的一刀：正性的无穷加法——非负性不被无穷加法保持（反例 W_S = 1、W − W_S = −2）。
  • ✓ 但把缺口从「缺对象」压到「缺符号」，是这一步的真正产出。

线三 · 外部证明 ◐ 外部事件

2026-11，外部证明撞进来（Alpöge × Claude，Lean 形式化 175,187 模块）。

  • ✓ 形式化层过关：全量编译 0 错误 + #print axioms 仅 3 条标准公理。
  • ✗ 数学理解为零——能验，不能懂。

线四 · 源码调查 ✓ 成功

从「验」退回「查源码」，厘清信任边界。

  • ✓ anyGeometry 可疑但未证实（恒真占位、真几何不进链）——嫌疑排除，但定义层被抽空坐实。
  • ✓ 短版 grh-lean（794 模块 / 约 11 万行）可安排验证：IP121（14G）构建通过 + 公理 5/5。

核心论点：地图的价值翻转

两个月做的「此路不通」地图，在外部证明出现后，价值从「指路」翻转为「解释新路为什么必须在图外」——因为被排除的 12 条路全在正性族，而证明用的是行列式族。

关键问题：新路为什么不需要正性？

这是四条线并流后浮现、且最值得回答的一个问题（综述 §6.3 第 2 条）。答案一句话：

行列式方法（Gram 行列式 / 协体积双侧夹逼）替代了正性。唯一用到的非负性是乘积公式 height(1) ≥ 0 与正型函数 Θ ≥ 0——都平凡且有限，绕开了「非负性不被无穷加法保持」的墙。

论证骨架（src/New/Main.lean 注释原文）：

h_main  ≤  (V + 2 δ) / rowDim  ≤  h_main − m·remainder

上界（short + enough forms）与下界（integral forms are long）夹住同一个 Gram 行列式；夹逼的缝 = 素数误差项，最后经 Landau 引理翻译成零自由区。
