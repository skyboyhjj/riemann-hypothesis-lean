# 读解：新路为什么不需要正性——行列式方法的替代机制

> 归档日期：2026-11-28 · 对象：`lsernau/grh-lean`（compact 版）`src/New/Main.lean` 的「spine of the proof」注释 + 关键文件
> 性质：回答综述 §6.3 第 2 条——「为什么这条新路不需要正性，它靠什么替代了正性」，基于对 Lean 源码骨架的直接阅读。

---

## 一、一句话结论

**这份证明用「行列式方法」（Gram 行列式 / 协体积的双侧夹逼）替代了 Weil 正性；它只用了两种「平凡」的非负性——正型函数 Θ ≥ 0（有限个 |·|² 的和）与乘积公式 height(1) ≥ 0——两者都是有限的，绕开了线二那堵「非负性不被无穷加法保持」的墙。**

## 二、论证骨架：一条夹逼不等式（★ 严格，字面可查）

`src/New/Main.lean` 顶部注释给出「spine of the proof」：

```
h_main  ≤  (V + 2 δ) / rowDim  ≤  h_main − m·remainder
```

- **上界**：定理 A（short forms）+ B（enough forms）给出协体积上界 `(V + 2δ)/rowDim ≤ h_main − m·remainder`。
- **下界**：定理 C（integral forms are long，经 Selmer 扭转 + 高度 + 行列式）给出 `h_main ≤ (V + 2δ)/rowDim`。
- **夹逼的缝** = `m·remainder`，即素数和的误差项（m ≈ √x 个 theta lift，m ∈ [√x, 2√x]，有限）。

结论：`remainder` 被双侧夹住 → `primeError ≤ x^(−1/2+8ε)`。

## 三、最后一步：Landau 引理把误差上界翻译成零自由区（★ 严格）

`src/New/Endgame/OneSidedCriterion.lean`：单侧界 `primeError ≤ x^(β−1)` ⟹ L(s,χ) 在 Re s > β 无零点（Landau 1905 / Montgomery–Vaughan §15）。这是「误差小 ⟹ 无零零点」的经典翻译，与正性无关。

## 四、唯一用到的「非负性」是两种平凡非负（★ 严格，字面可查）

1. **乘积公式**：`Heights.lean` 的 `HeightLe.nonneg (h : HeightLe c 1) : 0 ≤ c`——有理数高度的乘积公式（`log q + Σ_p ... = 0`），即「常数族 1 的高度 ≥ 0」。这是平凡的算术非负，**不是** Weil 的交形式正定。
2. **正型函数**：`OneDeterminant.lean` 的 `card_mul_sum_det_le` 要求 `Θ ≥ 0 of positive type`（来自 Poincaré 级数二阶矩 / Gram 矩阵）。正型函数的非负是「有限个 |·|² 之和」的固有性质，其作用是「positive-type functions avoid singular minors」——控制行列式为零（奇异 minor）的计数。

## 五、与线二那堵墙的对照（★半 / △ 推断）

线二判掉的是「非负性不被无穷加法保持」——Weil 正性要把局部正性**无穷加**起来证二次型正定，而无穷加法会破坏非负（反例 `W_S = 1`、`W − W_S = −2`）。

新路绕开这堵墙的方式：它的两种非负都是**有限**的——

- 正型 Θ 是有限个 theta lift 的 Gram 矩阵（m ≈ √x，有限）；
- 乘积公式是有理数在**有限多**个位的有限和。

于是「深」的正定二次型，被「上界与下界夹一个 Gram 行列式」的计数论证取代。正性在这里不是被证明，而是**不被需要**——它要解决的「把零点逼到线上」这件事，改由「误差项双侧夹逼 + Landau 引理」完成了。
