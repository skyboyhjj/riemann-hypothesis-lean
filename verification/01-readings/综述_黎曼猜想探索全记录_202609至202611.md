## §2 线一 · 把「缺一个理论」精确到一个格子

### 2.1 五条侦察线，同一个分界

两天之内扩出五条独立的文献侦察线，每条从不同入口进来，落到同一条分界上：

| 线 | 入口 | 落到哪 |
| :-- | :-- | :-- |
| **变分** | 朗兰兹对应有没有作用量 | 算术侧无，自守侧有 |
| **正性** | 函数域的 RH 靠什么证 | 靠 `C×C` 上的**代数指标定理**（正性） |
| **造曲线** | 能否造一条「绝对 `𝔽₁`-曲线」 | Connes–Consani 2026 造出来了，**但不含正性** |
| **λ-运算** | Borger 的 λ-环 ⟷ `𝔽₁` | 是真实的连接（见 2.3 的更正） |
| **THH** | Tate 构造 / Hesselholt 的 `TP` | 特殊值有了，整图仍空一格 |

**五种说法，同一个分界：函数域 vs 数域。**

### 2.2 精确到一格

最后收成一句话：

> **「一元」（两本账）处处是定理；缺的从来不是统一，而是「把一种正性变成另一种正性」的那座桥。**

再收一层，落到具体一格：**`(Spec ℤ, 零点结构)`** —— 这一格是空的。

配套的两章是这条线的主干：

| 章 | 结论 | 分级 |
| :-- | :-- | :-- |
| **已证样板章：函数域** | 两本账 = 定理；正性 = 定理（交形式正定）；那个 `F` = 看得见的几何对象 | ★ 严格 |
| **缺口章：数域** | 两本账 = 定理（显式公式，数值校验误差 0.07%）；`F` = 写得出来（Weil 二次型）；**正性 = 未证 ⟺ RH** | ★ 严格 |

**函数域上「找不到的那个 `F`」是交形式，它的正定性是一条几何定理。数域上 `F` 也写得出（Weil 二次型），但它的定号问题就是 RH 本身。**

### 2.3 这条线里三次自我更正（都值得记）

| 更正 | 原判 | 更正后 |
| :-- | :-- | :-- |
| Borger 是不是孤岛 | 曾记「Borger ⟷ CC 零引用，是地图上唯一孤岛」 | **撤回**：CC 2020（`arXiv:2004.08879`）明确引用 Borger 2009，§2.3 标题即「λ-rings and the Arithmetic Site」。**地图上没有孤岛** |
| 生克矩阵「不可约」 | 曾说 R 不可约 | **只能在「置换单循环」义下用**：作为矩阵，R 在 ℝ 上可约（常数模是 1 维不变子空间） |
| Connes 的算子 Δ 是否自伴 | 曾按「自伴 ⟹ 实谱 ⟹ RH」的形态理解 | Connes 1999 的 Δ 因给 Haar 测度加权而**非自伴**；零点是**吸收谱**。「自伴 ⟺ RH」只是 Hilbert–Pólya 式的概念形态，不是构造现成的性质 |

第三条更正最重要：**它把「Connes 路线已经做到一半」这句话，改成了「Connes 路线做出了对象，但那个对象不是自伴的」。**

### 2.4 一张矩阵表的精化

做过一张「一元 × 正性」矩阵，逐条查「恒等式证完了吗、正性呢」。结论被精化得很关键：

> **正性缺口不在整个「迹公式／谱-几何」这一类，而在一个很具体的子类：数域 + 无限维自伴谱 + 含阿基米德位。**

分界线只有一条：**函数域 vs 数域**。

## §3 线二 · 把缺口从「缺对象」压到「缺符号」

线一给了一个格子；线二把这个格子里的困难拆开，一条条试，一条条排除。

### 3.1 上游四步：把「RH」换成「正性」

| 步 | 做了什么 | 结果 |
| :-- | :-- | :-- |
| 1 | 椭圆曲线试验台：局部有定理、整体没有，断点在哪 | 断点 = **从有限乘积变成无穷 Euler 积**（`ℚ` 上必须解析延拓） |
| 2 | 「缺的是有限性」这个猜想成立吗 | **不成立**：`T_ℓ(E) ≅ ℤ_ℓ²` 早就是 2 维有限秩；缺的是**统一的整体算子** |
| 3 | Connes 路线：把 RH 化成谱的实性 | 三件套齐（adele class space / scaling 流 / trace map）；`Δ` 的谱是实 ⟺ RH，但 `Δ` 非自伴 |
| 4 | Weil 正性：RH ⟺ 一个二次型恒正 | 判据准确：`RH ⟺ Σ g̃(ρ)g̃*(1−ρ) > 0`；把「位置问题」变成「**符号问题**」 |
| 4′ | semilocal 情形：有限 places 怎么样 | **正性免费**（测度 = ∏|L_p|² ≥ 0）；加一个素数就变成 q = 1/p 的幂级数；**缺口 = 正性的「无穷加法」** |

第 4′ 步是整条线最锋利的一刀：

> **非负性不被无穷加法保持。** 举例：`W_S = 1` 恒正、`W − W_S = −2`，则 `W = −1 < 0`，而任何有限截断都察觉不到。

这一刀直接判掉了所有「有限截断」类策略——数值验证、有限 places 截断，注定不够。

### 3.2 中游 P0–P21：收束到一个 Hermite–Biehler 条件

十八项到二十一项探索（P0–P21），把 Weil 正性一路收束到**同一个点**：

> 函数 $E(z)=\xi(1/2-iz)+\xi'(1/2-iz)$ 的 **Hermite–Biehler 性质**。
>
> 它等价于：$\mathrm{Re}(\xi'/\xi)>0$ 在 Re(s) > 1/2 上恒成立 ⟺ RH ⟺ Suzuki 与 CCM 的极限 ⟺ Weil 正性。

这一段的净进展是**定位**，不是证明：

| 层 | 状态 |
| :-- | :-- |
| ① 信息层 | **不缺**（收敛域值唯一确定解析延拓） |
| ② 构造层 | **已解决**（五个显式对象：Sonin 投影、`A_a`、`E`、矩 `Σ_k`、Cauchy 核） |
| ③ 符号层 | **缺口在此**（把对象连到 ζ 的那一步，全部不免费） |

> **一句话：从「缺对象」推进到「缺符号」。**

### 3.3 下游五步：五个对象，同一个困难

依次试了：矩出口 → Cauchy 核 → 换核 → 整体对象 → 算术输入。结果：

| 试法 | 为什么不通 |
| :-- | :-- |
| 矩的首项支配 | 只在 `ε ≲ δ(t)` 时成立，而 `inf δ(t) = 0` |
| 换核（找又快又窄的核） | **Paley–Wiener 对偶**：灵敏度 ~ 1/c 与可算性 c > 1/2 不可兼得 |
| 换对象（另找一个整体对象） | 五个对象的「不免费部分」**是同一个困难**（参数 `a ↔ S ↔ T_n ↔ ε ↔ c` 已逐个对上） |
| 靠现有算术定理 | 最强的零自由区只给 0.0004–0.005 的分辨率，需要 0.5；次凸性同类，仍差 0.5 |
| 找「免费的 manifestly-positive 对象」 | **不存在**——对象免费给的都**是等式** |

### 3.4 排除清单：12 条，给未来的自己

这是线二最硬的产出——**不是「我证了」，而是「这些路走过了，不必重走」**：

| # | 被排除的路 | 依据强度 |
| --: | :-- | :-- |
| 1 | 用局部信息（每个素数的 Frobenius）拼整体零点 | ★ |
| 2 | 「缺有限性」——找有限维表示 | ★ |
| 3 | 镜像对共享「正性因子」、正性传播 | ★ |
| 4 | Weil 正性 ⟺ PF 单值群谱的实性 | ★ |
| 5 | 有限三角多项式机制 | ★ 半 |
| 6 | 半有限 / 近似函数方程（AFE） | ★ 半 |
| 7 | 矩的首项支配 | ★ 半 |
| 8 | 换核（同时要快衰减与窄） | ★ 半 |
| 9 | 换对象（另找整体对象） | ★ 半 |
| 10 | 依赖现有算术定理 | ★ 半 |
| 11 | 找「免费的 manifestly-positive 对象」 | ★ 半 |
| 12 | 只靠函数方程定零点位置 | ★ |

**另两条被降级而非排除**：矩方法（不是错，是局部）；Cauchy 核（保留为技术资产，唯一「谱侧 = 解析量」的核，但受 `ε > 1/2` 限制）。

### 3.5 四个独立见证，一个墙

| 见证 | 表述 |
| :-- | :-- |
| 绝对收敛墙 | 经典机制只到 `σ > 1` |
| 零点密度障碍 | 特征函数零点密度 `a/π` 无法对消到 `log T / 2π` |
| Paley–Wiener 墙 | 灵敏度与素数侧可算性由同一个奇性距离 `c` 控制 |
| 零自由区 | 已证的零自由区与所需分辨率差两个数量级 |

**四条来自不同方向的路，撞到的是同一堵墙。** 这一致性本身，是「缺口在符号层」这个判断最强的旁证。

### 3.6 这条线的诚实边界

| 强度 | 内容 |
| :-- | :-- |
| ★ 严格 | 九种等价写法；排除清单第 1、2、3、4、12 条；技术资产里的恒等式部分 |
| ★ 半严格 | 排除清单第 5–11 条（数值证据充分，非解析证明） |
| △ 假设级 | 「恒等式免费、符号不免费」是提炼不是定理；「需要新算术」是判断不是证明 |

## §5 线四 · 源码级调查与短版

### 5.1 anyGeometry：一个从 grep 长出来的问题

Chu 提的问题很具体：`Main` 的证明链到底走不走 `anyGeometry`？而 `anyGeometry` 的定义是——

```lean
fun _ _ _ => True
```

即：**把「真实几何」换成了一个恒真谓词。** 如果它在关键位置承担实质工作，那这个形式化证明在「定义名副其实」这一层上就有问题。

我们从五层往上查：

| 层 | 方法 | 结果 | 是否定论 |
| --: | :-- | :-- | :-- |
| 1 | 文本定位（grep） | 24 个文件提到，零 `instance` 字段 | ★ 硬 |
| 2 | 轻量常量判据 | 24/24 在闭包内——**但这只是平凡事实** | ★ 硬 |
| 3 | 源码级链追踪 | 从 `riemannHypothesis` 追到 `anyGeometry`，显式可列 11 跳 | ◐ 中 |
| 4 | 语义定性 | `oAt_any` 只要 `Lam3`；`oAt_geoOf` 要多一个 `IsGeoOf` 假设 | ★ 硬 |
| 5 | 综合 | 无桥接步骤把 anyGeometry 成员转成 geoOf 成员 | ○ 弱 |

第 4 层是全篇最硬的一条，因为它**不需要追踪任何东西**：同一个位置两个构造子，差别恰恰是「要不要那个几何假设」。**「lam 不蕴含几何」这件事，是代码作者自己写下的设计，不是分析者推断出来的。**

第 5 层是全篇最有分量的一句，而它的证据是 ○ 级。当时我们写下的结论是：

> 源码追踪能支撑「高度可疑」，不足以支撑「已证实为空」。根因不在方法，在对象——**原版 17.5 万个文件只有一处注释，没有一个可以按图索骥的入口。**

### 5.2 短版把「不可审」变成「可安排」

11-25 出现的短版，对这个悬案的影响不是「解答」，是**改变了成本结构**：

| 项 | 原版 | 短版 compact |
| :-- | :-- | :-- |
| `anyGeometry` 出现 | 24 个文件 | **0 次** |
| 定义体直接写 `True` 的 Prop | — | **0 处** |
| `sorry` | — | **0 处** |
| 阅读入口 | 无导读，17.5 万文件一处注释 | **GUIDE.md 27 KB**，明确写了读法 |
| 信任路径 | 不可估 | 读 `Statements.lean` + `Main.lean` 五行 + 公理列表，三步 |

**能说的**：短版在源码字面上没有那个谓词，且信任路径短到可以人工走通。

**不能说的**：短版没有「证明 anyGeometry 无害」，也不能说「它用别的方式承担了同样的角色」——`Lib/` 285,088 行没有逐行审。

**但方向变了**：从「用 grep 在 1700 万行里摸」，变成「按 GUIDE 走 47 万行里的指定十几节」。

### 5.3 「76,000 行」这个数字

短版最有名的数字，实测对不上：

| edition | README 声称 | 实测（commit `72fead10`） | 倍数 |
| :-- | --: | --: | --: |
| `grh/`（可读版） | 300,000 | **477,151** | 1.59 |
| `grh-compact/` | 76,000 | **112,854** | 1.48 |

链条是：README → Sutherland 页照抄 → explainx 明说「We use the README figures」→ 中文媒体写「暴砍 99.56%」。**四个环节，零次实测。**

更要紧的是结构：行数砍了 76%，同版本内**本项目自有声明只砍了 23%**，导出体积反而 +15%。**短的是写法，不是证明。**

## §6 四条线在哪里交汇（这是整篇最重要的一节）

### 6.1 一个必须先说清的区分

否则这篇会自相矛盾：

> **「RH 是否为真」与「现有通用工具能否证明它」是两个问题。**

Lean 那份证明（若被数学家消化）就是 RH 的证明——**这不需要我们那 12 条排除清单点头**。

我们那 12 条讲的是另一件事：**为什么用 Connes、Suzuki–de Branges、矩、次凸性这些公开工具，走到符号层就走不动。**

所以正确的读法是：

| 我们的探索 | 不是 |
| :-- | :-- |
| 「已知的十几条路都撞到同一堵墙」 | ✗ 「RH 不可能被证明」 |
| 「正性这一族工具不够用」 | ✗ 「任何工具都不够用」 |

### 6.2 真实的对照：真实证明走的是第 18 条路

这是把四条线并起来看才浮现的东西。

我们排除的 12 条、加上试过的 5 个对象，全部落在**同一个族**里：**正性、谱、符号**。它们的共同形态是——找一个对象，使某个二次型恒正，而这件事等价于 RH。

而短版的 `New/` 目录名告诉我们，Alpöge–Claude–Sernau 走的完全是另一族：

| `New/` 子目录 | 行数 | 干什么 |
| :-- | --: | :-- |
| `Spanning` | 59,251 | 张成（short forms / enough forms） |
| `UpperBound` | 35,318 | 上界（行、列、链、Poincaré 映射） |
| `Congruences` | 34,811 | 同余 |
| `Determinant` | 21,707 | 行列式（integral forms are long） |
| `OneLift` | 17,323 | 单次提升（`W_j → V_j`） |
| `Derivatives` | 12,391 | 导数 |
| `Reduction` | 6,153 | 化归（数据、格、高度、主不等式） |

**张成 · 上界 · 同余 · 行列式 · 提升——这是行列式方法与计数论证的词汇，不是正性与谱的词汇。**

GUIDE 里的参数表也印证：`m` 是 2 的幂、在 `[√x, 2√x]`；`r` 是 3 的幂、在 `[x⁵, 3x⁵]`。这是**对长度为 x 的素数加权求和、取链长 √x** 的构造——正是「用 theta lift 链模拟 Stepanov 方法中的重数」那个思路。

### 6.3 所以缺口分析的价值，现在变成了另一件事

原来我们以为它的价值是「逼近 RH」。现在看更准：

> **它给出的是一张「此路不通」的地图，而真实证明从地图外走了进来。**

三件具体的事可以立刻做：

1. **核对**：`New/` 那五个目录里，有没有任何一处依赖一个「恒真」的定义来充当几何或算术条件？短版此前的答案是「`anyGeometry` 0 次、`: Prop := True` 0 处」——但这只是字面扫描。
2. **解释**：为什么这条新路不需要正性？它靠什么替代了正性？（猜测：Stepanov 重数法靠「计数上界与下界相撞」，本质是一种**反证式的定量矛盾**，而不是构造一个正定对象。）
3. **迁移**：这条路的哪一部分可以搬回我们的地形图？`UpperBound` 的「上界链」与我们的「Paley–Wiener 墙」是同一个东西的两面吗？

第 2 条如果做出来，是这三个月里最值得写的一件事。

### 6.4 一处具体的接点：Schoenfeld 界

短版之外，Sutherland 还做了一个 `schoenfeld-rh-lean`，证明：

> $|\psi(x)-x| < \sqrt{x}\log^2 x/(8\pi)$ 对所有 x ≥ 73.2 成立，与 RH 等价。

我们用筛法精确算 ψ(x) 到 10⁶，核这条界：

| 量 | 值 |
| :-- | :-- |
| 界在 74–10⁶ 内是否处处成立 | 是 |
| 最紧处 | `x = 96`，右边只比左边大 **1.24 倍** |
| 最松处 | `x = 768657`，比值虚高 2×10⁷（分母趋零的伪影） |

**最紧处在 x = 96，几乎撑满。** 这说明常数 `1/(8π)` 不能再明显收紧（若误写成 `8π`，界宽 632 倍，最小处立刻暴露）。

而这条界正是我们线一那条显式公式的另一副面孔——**`ψ(x)` 的两本账**。它把「抽象命题」换成了「一条能在 1976 年文献里逐字对上的显式不等式」。**这是我们这条线一直在做的事（把缺口写成可陈述的东西）在外部世界的对应物。**

## §9 三句话

**第一句：我们花三个月证明的是「路不通」，不是「走不到」。** 12 条排除 + 5 个对象，全部落在正性—谱—符号这一族；同一堵墙从四个方向被撞到，这本身是一份有用的地图。

**第二句：真实证明从地图外走了进来。** `Spanning / UpperBound / Congruences / Determinant / OneLift` —— 张成、上界、同余、行列式、提升，这是另一族的词汇。**缺口分析现在最大的价值，是解释「为什么另一族能行」，而不是继续在原地找正性。**

**第三句：能验的与能懂的，这一个月里被彻底分开了。** Lean 验了「命题为真」，没验「定义名副其实」，更没提供「为什么」；Calegari 说这就是新常态；而我们要问的，一直是那个「为什么」。
