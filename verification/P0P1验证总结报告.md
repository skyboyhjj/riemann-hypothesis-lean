## 一、背景与动机

上游 Alpöge × Claude 证明发布后，争议焦点之一是 `anyGeometry`：一个恒真几何谓词 `fun _ _ _ => True`，在证明链上被实质使用，而真实几何谓词 `IsGeoOf` 从不进链。据此产生两种解读：

- **(A)** `anyGeometry` 是正确抽象，证明本就不需要那个几何谓词层；
- **(B)** `anyGeometry` 掏空了 Langlands「自守 L = 几何 L」的桥梁，证明缺失关键一环。

本项目先前对上游（175,187 模块）的读解停在「倾向 (B)，需数学专家裁决」。Sernau 精简版提供了一个**决定性判据**：它把整个几何谓词层重写删除，若删掉后证明仍闭合，则坐实 (A)、排除 (B)。

---

## 二、P1 · anyGeometry 去留（源码审计）

### 方法

对 `grh-compact/src` 全量 grep 扫描几何谓词与自引公理关键字。

### 发现

| 扫描项 | 命中数 | 含义 |
| :-- | --: | :-- |
| `anyGeometry` | **0** | 恒真几何谓词被彻底删除 |
| `IsGeoOf` | **0** | 真实几何实现谓词被删除 |
| `geoOf` | **0** | 真几何条件被删除 |
| `HasTrueSurf` | **0** | 真实曲面条件被删除 |
| `axiom` / `constant` 关键字 | **0** | 无自引公理 / 常量（18 行命中均为注释里的数学术语） |

### 真实几何论证完整保留

精简版仍含 `src/Lib/Shimura`、`src/Lib/Cohomology`、`Trace`、`GaloisRep`、`Selmer`、`Patching` 等——证明核心是 **theta 对应（theta lifts）+ 高度估计 + 素数计数**（Gelfond–Schnirelman + Bombieri 曲线点计数），核心不等式为 `h_main ≤ (V+2δ)/rowDim ≤ h_main − m·remainder`。

### 结论

删除 `anyGeometry` 后证明仍闭合 → 若它是必需桥梁 (B)，删掉就无法闭合；既然闭合，**坐实 (A)、排除 (B)**。精确表述：`anyGeometry` 是「死脂肪」，不在证明必要路径上；真实几何论证从未缺失。

## 六、边界与遗留（诚实声明）

P0+P1 坐实的是「可编译、3 公理、anyGeometry 是死脂肪」这三点，**不等于「证明已由人类数学家确证」**。仍在外的关键问题：

1. **解析/矩阵不等式的数学正确性**：17M→7.6 万行里真正「干活」的 `DivInputsR` / `WordFacts` / `LinkGLOBAL` 等核心，是唯一需要人类数学家逐行啃的部分（Kevin Buzzard、Terence Tao 均表态「真正工作是逆向工程黑盒、剪 bloat、提炼人读证明」）；
2. **Mathlib 的 `RiemannHypothesis` 定义链**（依赖 `riemannZeta` 及其解析延拓）；
3. **内核/检查器 soundness**（2026-07 刚出过嵌套归纳类型漏洞）。
