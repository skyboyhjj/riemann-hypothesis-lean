## 一、命题层 · 语句审计（所证即 RH）

### 方法：方案 A（类型检查等价）

建只 `import Mathlib` 的隔离文件，写 `example : Mathlib.RiemannHypothesis := riemannHypothesis`，靠内核类型检查判定「定理类型 = Mathlib 官方 RH 命题类型」。辅以 `#print` 展开定义、`#check` 核对五定理类型。

### 结果

- `RiemannHypothesis`（Mathlib）与 `RiemannZetaZerosOnLine`（Statements）**逐字一致**——不是「等价」，是「完全相同」。
- 五定理类型核对：定理 1 直接是 `RiemannHypothesis`；定理 2 是 `RiemannZetaZerosOnLine`；定理 3/4/5 覆盖三个 Dirichlet L 的 GRH。

### 边界（必须写明）

方案 A 只证「所证命题 = Mathlib 的 `RiemannHypothesis` 定义」；「Mathlib 定义 ≙ 教科书经典 RH」这一层是 **Mathlib 官方的责任，本项目不代验**。备选方案 B（con-leche `--compare`，需导出 61.5 GB）更严格但未采用。

## 三、内核层 · 编译 + 内核重放 + 交叉

### 3.1 全量编译

175,187 模块（level 0 的 5,927 + level 1–202 的 169,260），**0 错误**，61.54h，203 层依赖拓扑、0 循环依赖。

### 3.2 leanchecker 定向内核重放（阶段 3.5）

对全部自定义 `macro` / `elab` / `syntax` 定义所在模块 + 唯一 `addDecl` 模块 `CutCptCopy`，共 **30 个模块**逐一 `lake env leanchecker` 重放：**30/30 通过，0 失败**，未发现 metaprogram 构造不一致 Environment 的痕迹。

> 口径：leanchecker 是**同内核**重放（排除 elaborator/metaprogram 的 environment hacking），非独立内核（那是 Sutherland nanoda/con-leche，属 TCB 层）。定向重放的充分性由「0 `unsafe` 扫描」支撑——无 unsafe 则元程序无法绕过内核。

### 3.3 双机交叉（IP47 ↔ IP121）

20 个候选代表模块中，**14 个可逐字节比对且 14/14 SHA-256 全等**；另 6 个因 olean 嵌入绝对路径（linter 告警，两机构建目录不同）不可比——**非编译失败、非证明不一致**。

## 四、定义层 · anyGeometry（本项目的增量价值）

这是内核检查**管不到**的一层，也是本项目相对「纯内核验证」多补的缺口：

- `anyGeometry` 恒真（`fun _ _ _ => True`），且**在证明链上被实质使用**。
- 真实几何谓词 `IsGeoOf` **从不进证明链**——几何侧被整体抽空。
- 外部佐证（Nielsen 消融实验）：该字段可整体删除、真几何下高度估计失效。

**定性**：语法上不污染（`EveryCharacter` 命题干净，不依赖 Γ）；但语义上「真实几何」这一 Langlands「自守 L = 几何 L」的桥梁**从未建立**。残余判断需数学专家——形式化无法自动区分「anyGeometry 是正确抽象」与「anyGeometry 掏空了关键几何一环」。

---

## 五、TCB 层 · 可信基

Lean 4 内核本身、编译器、系统与硬件的可信基，**不在本项目范围**。与 Sutherland（MIT）的分工：其 nanoda/con-leche 做独立内核重放（TCB 层）；本项目补依赖结构测绘、定义层、leanchecker 同内核定向重放三个角度。

---

## 六、总体结论

1. **可编译**：175,187 模块 0 错误。
2. **公理干净**：仅 3 条标准公理。
3. **所证即 RH**：与 Mathlib 定义逐字一致。
4. **无 metaprogram 篡改**：leanchecker 30/30 + 0 unsafe。
5. **双机可复现**：14/14 逐字节一致。
6. **定义层有口子**：`anyGeometry` 恒真、真实几何不进链——这是内核之外、需人工/数学专家进一步判断的一环。

> 一句话：**「通过 Lean 是形式自洽」与「逻辑自洽需要更多人验证」二者都成立**——本报告坐实前者（可编译、三公理、所证即 RH、无篡改），并明确后者（定义层 anyGeometry 的实质缺口需数学专家定夺）。
