核心争议：anyGeometry

争议集中在证明链上的几何谓词 anyGeometry。两方立场如下：

方主张核心论据
Nielsen（质疑） 证明是循环论证，缺乏实质数学内容 ① anyGeometry := fun _ _ _ => True 恒真；② 退化模型 geoDegenerate / mdlJunk（零体积、空曲面、格映射送 0）；③ setDiv 用解析公式 hExpl6 覆写高度字段，靠 rfl 闭合
技术中立反驳 anyGeometry 是「死脂肪」，不使证明作废 定理 riemannHypothesis : RiemannHypothesis 零输入假设、零 sorry、零额外公理，无法从 True / rfl 变出；Nielsen 复现时被迫把 RH 作为输入假设传回

本站结论（2026-11-27 · P1）：本站对 Sernau 精简版（约 11 万行）做源码审计，anyGeometry / IsGeoOf / geoOf / HasTrueSurf 全 0 命中、无 axiom/constant 关键字；删掉几何谓词层后证明仍闭合（3 公理）→ 坐实「短版不依赖 anyGeometry」，真实几何论证（theta 对应 / Shimura / 上同调 / Galois 表示）完整保留。但不能反推「原版 anyGeometry 无害」（短版用 other arguments 重写、Lib 285k 行未逐行审），原版 (A)/(B) 仍悬置。

对本项目结论的影响

本项目读解原先停在「倾向 (B) vs (A)，需数学专家裁决」。经 P1 对 Sernau 精简版的源码审计，坐实的是「短版不依赖 anyGeometry」（原版 (A)/(B) 仍悬置）：

  • 源码实证：Sernau 精简版删除 anyGeometry 后证明仍闭合 → 坐实「短版不依赖 anyGeometry」；但短版用 other arguments 重写、Lib 285k 行未逐行审，不能反推「原版 anyGeometry 无害」。
  • 但这不等于证明已确证。审查焦点随之前移至三处：① 解析/矩阵不等式核心（DivInputsR/WordFacts/LinkGLOBAL，17M 行里真正「干活」的部分）；② Mathlib 的 RiemannHypothesis 定义链；③ 内核/检查器 soundness。

本站立场：继续独立复现，不因「多检查器通过」而停止、也不因「anyGeometry 恒真」而否定——真正待啃的是解析核心的数学正确性与定义层是否名副其实，这正是本项目「定义层验证」的立足点。
